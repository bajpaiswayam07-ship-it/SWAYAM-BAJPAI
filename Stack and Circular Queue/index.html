📚 Core Stack Mechanics

  • Top Pointer: Starts at -1 when empty. Increments on push() and decrements on pop().
  • Overflow Condition: Occurs when attempting to push onto a full stack: top == capacity - 1.
  • Underflow Condition: Occurs when attempting to pop from an empty stack: top == -1.
  • Contiguous Memory: Elements sit in successive memory addresses (4 bytes each).

🧮 The Mathematical Formulas

  • Enqueue Formula: rear = (rear + 1) % capacity
  • Dequeue Formula: front = (front + 1) % capacity
  • Queue Full Condition: (rear + 1) % capacity == front (or tracking count == capacity)
  • Queue Empty Condition: front == -1 (or count == 0)
